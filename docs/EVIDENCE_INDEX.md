# Evidence Index

Internal-only evidence lives in the original research workspace (`qsite-2026`, not part of this
repository) and in the review packages under `../review-packages/`. This index records, for every
figure in `results/`, its source artifact and hash pointer so results remain auditable without bundling
internal material.

> Convention: paths under `qsite-2026/` are relative to the **original research workspace root** (the
> read-only parent project of this repository, which is internal and not part of this repository).
> `review-packages/` is relative to this repository. No historical archive is bundled; each is linked
> by SHA-256.
